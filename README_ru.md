# Телеграм-бот: отчёт по цене электроэнергии для Латвии (Elering / Nord Pool)

Бот раз в час отправляет в Telegram отчёт по **спотовой цене** электроэнергии для Латвии (LV), 
сравнивает её со **средним значением за последние 30 дней**, и **помечает 🔴**, если текущая цена выше среднего на **50% и более**.

> Источник данных: открытое API Elering (соответствует Nord Pool day‑ahead).  
> Эндпоинты: `/api/nps/price/<country>/current` и `/api/nps/price/csv?start=...&end=...&country=LV`.

## Быстрый старт

1) Установите Python 3.10+.
2) Скачайте и распакуйте архив проекта (или `git clone` этого каталога).
3) Создайте `.env` на основе `config.example.env` и заполните:
   - `TELEGRAM_BOT_TOKEN` — токен бота (BotFather).
   - `TELEGRAM_CHAT_ID` — ID чата/канала, куда слать сообщения (для каналов используйте отрицательный ID или `@username`).
4) Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
5) Запустите бот‑демон, который сам будет слать отчёты раз в час (в hh:00 по вашему времени):
   ```bash
   python bot_daemon.py
   ```

### Одноразовый запуск (для cron)
Если хотите посылать сообщение из cron, используйте:
```bash
python send_report_once.py
```
Настройка cron (раз в час):  
```cron
0 * * * * /usr/bin/python /path/to/send_report_once.py >> /var/log/lv_price_bot.log 2>&1
```

## Как работает
- **Таймзона:** Europe/Riga.
- **Текущая цена** берётся из `https://dashboard.elering.ee/api/nps/price/LV/current`.
- **Средняя за 30 дней** — из CSV `https://dashboard.elering.ee/api/nps/price/csv?start=...&end=...&country=LV`.
- Формула превышения: `((current / mean_30d) - 1) * 100%`.
- Если превышение `>= 50%`, сообщение помечается `🔴` (в Telegram нет нативной окраски текста в красный).

## Файлы
- `bot_daemon.py` — длительный процесс с планировщиком (каждый час).
- `send_report_once.py` — одноразовая отправка (удобно для cron).
- `elering_client.py` — работа с API Elering (получение цен).
- `telegram_client.py` — простая обёртка для отправки сообщений без сторонних библиотек.
- `requirements.txt` — зависимости (минимально необходимые).
- `config.example.env` — шаблон конфигурации.
- `LICENSE` — MIT.

## Примечания
- С октября 2025 в ЕС начали внедрять **15‑минутную** дискретизацию. Если API вернёт 15‑минутные точки,
  скрипт агрегирует их в часовое среднее автоматически.
- Если Elering временно недоступен, сообщения пропускаются, а ошибка логируется.
- При необходимости адаптируйте код под другие страны: `country = "LV"` → `"EE"`, `"LT"`, `"FI"`.
